# Vertical slices

1. **Connect and inspect received mail** — no blockers. Private token-file connection, account check, paginated Inbox listing/read/search, JSON errors.
2. **Read attachments and draft responses** — blocked by 1. Safe downloads; new and genuine threaded reply drafts, no send capability.
3. **Organise with verified undo** — blocked by 1. Frozen plans, explicit topic assignments, journaled apply/undo and interrupted-write reconciliation.
4. **Install, OAuth and release** — blocked by 1–3. Portable skill, optional MSAL sign-in, setup/reconnect guidance, CI, security/spec review and sanitised GitHub release.

Acceptance and test evidence are recorded in docs/verification.md before release.
